# Muzahidul Islam - Portfolio

Static site: HTML, CSS, JavaScript and Bootstrap 5. No build step.

## Run it
Open `index.html` in a browser (needs internet for Bootstrap, icons and Google Fonts),
or deploy the folder as-is to GitHub Pages / Netlify.

## Folders
| Folder | What it is |
| --- | --- |
| `index.html`, `style.css`, `script.js` | Main portfolio |
| `assets/` | Profile photo, CV, project thumbnails |
| `project-1/` | Liberation War Archive (5 pages) |
| `project-2/` | Alfa Omega Security Group (concept site) |
| `project-3/` | Alfa Omega Textile Trading (concept site) |
| `Digital-Clock/` | Digital Clock |
